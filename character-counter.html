Character limits for popular platforms

Every platform counts text a little differently, so it helps to see your draft against each limit while you write. Paste your text above and the bars show how close you are to each one. A row turns red when you go over.

Instagram caption and bio limits

An Instagram caption can hold up to 2,200 characters, and a bio up to 150. Long captions are cut off after the first few lines with a “more” button, so lead with your hook and keep the key message near the start. Hashtags count toward the 2,200 characters.

X (Twitter) character limit

A standard post on X can be up to 280 characters. Links are counted as a fixed length however long they are, and some characters, such as emoji, can count as more than one. Use the count here as a close guide and check the post box before you publish.

LinkedIn, YouTube, and Facebook

  • LinkedIn post: up to 3,000 characters.
  • YouTube title: up to 100 characters, though long titles are often shortened in search results. The description can hold 5,000.
  • Facebook post: up to 63,206 characters, far more than most people need.

SEO title tags and meta descriptions

Search engines show only part of a page’s title and description. A title of about 50 to 60 characters and a description of about 120 to 160 usually display well. The real cutoff is measured in pixels, so wide letters like “W” take up more room, and Google sometimes rewrites the snippet it displays. Treat these numbers as a guide.

SMS length

A single text message holds 160 characters when it uses the standard GSM character set. Adding emoji or some non-Latin letters switches the message to a mode with a much shorter limit, so a longer message may be split into several parts.

Frequently asked questions

How many characters can an Instagram caption have? An Instagram caption can be up to 2,200 characters and a bio up to 150. Only the first part of a long caption shows before the “more” button, so put the important words first.

How many characters can a post on X have? A standard post on X is limited to 280 characters. Links are counted as a fixed length no matter how long the address is, so the count here is a close guide rather than an exact match. Some paid accounts can write longer posts.

How long should a meta description be? Aim for roughly 120 to 160 characters. Google cuts descriptions by pixel width, not by character count, so the exact cutoff varies, and it sometimes rewrites the description it shows.

Do spaces count as characters? Yes, on most platforms. This tool shows the total and the count without spaces, so you can use whichever one your platform needs.

Is my text sent anywhere? No. Counting happens in your browser, and nothing is uploaded or stored.
